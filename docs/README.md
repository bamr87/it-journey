# it-journey documentation

> Every document in this repository, one line each — start with the root README, and see AGENTS.md for how to work here.

**Backlog of record:** GitHub Issues with the fleet labels (`.github/sdlc.yml`, mode `issues`).

Start with the root [README](../README.md) for what IT-Journey is, then [AGENTS.md](../AGENTS.md) for commands, layout and the quest and frontmatter rules. `docs/` is excluded from the Jekyll build: link these files from site pages with a GitHub URL, never a site path. `docs/reference/` is generated (`make docs`); edit the workflow files or the Makefile instead.
