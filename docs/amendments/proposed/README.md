# docs/amendments/proposed/ — unnumbered amendment records

Proposed constitution amendments that have no number yet. Each one is named by slug and carries `**Number:** NEW`, following the hub convention (bamr87/bamr87 `docs/amendments/proposed/`, hub amendment 0002). When the maintainer ratifies a record by merging it, the record is numbered into `../NNNN-<slug>.md` and its row in [the index](../README.md) moves to ratified. Process: [constitution § 8](../../constitution.md).
